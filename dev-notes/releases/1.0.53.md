## VesperTV 1.0.53 (beta) — *hot fix*

Android TV, Fire TV and Android phones - build 556

A *hot fix* for two problems reported on 1.0.52.

### Movies & TV shows
- An episode or movie whose stream cuts out mid-way no longer restarts from the beginning: the player reconnects and continues where it stopped.

### Google TV / Chromecast
- After typing in a text field, the remote's arrows leave the field again (the 1.0.52 fix did not work on Google TV's keyboard).

### Windows
Windows remains at **1.0.45**. This release contains an Android APK only; Windows has not been rebuilt or tested for these changes. Its existing download remains available on the website and the 1.0.45 release.

### Install
Update through Settings > Check for Updates, download app-release.apk, or use Downloader code **1760256**. Install over your existing app to keep your setup.
