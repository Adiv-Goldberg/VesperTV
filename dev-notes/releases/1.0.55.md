## VesperTV 1.0.55 (beta)

Android TV, Fire TV and Android phones - build 599

### Multiview
- Multiview was reworked: screens now follow Add / Remove, there is an OK menu, a **1 + 3** layout with **Swap mode**, and channels are picked through the Live TV panel.
- Sports Trak: hold OK on a live game > **Play in Multiview**. Check up to 4 live games, then Open Multiview shows them as equal screens.

### Sports Trak
- Leagues now sit in a left rail of logos; press the arrow to show their names (remembered per device).
- The Live TV panel has a **Live now** group: one row per live game on its best channel, hold OK to see that game's sources.

### Media Hub
- Episodes the catalog doesn't list yet (a daily show's newest episode, for example) now appear as **Not listed yet** and play if your sources already have them. With your TMDB key the list is more accurate. If there is no stream yet, you see "No playable stream for this title."

### Playback
- Live TV: a stalled connection now gives up after 30 seconds instead of repeating, and the **Live buffer** has a Gradual option.
- **HLS stream format** option for providers that serve live channels as HLS.
- If a playlist's server can't be reached, the app now retries once and then stops loading that playlist's movies and shows in the background, instead of timing out category after category.

### Big playlists
- Better handling and diagnostics for playlists with hundreds of thousands of channels. If the app is slow with a very large playlist, please send a log (Settings > Send log) after a few minutes of use.

### Support
- Donations are paused while we move to GitHub Sponsors. VesperTV stays free, with no ads and nothing locked.

### Windows
Windows remains at **1.0.45**. This release contains an Android APK only.

### Install
Update through Settings > Check for Updates, download app-release.apk, or use Downloader code **1760256**. Install over your existing app to keep your setup.
